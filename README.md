# 🌰 خانم گل | فروشگاه اینترنتی خشکبار — نسخه Vue 3

فروشگاه اینترنتی خشکبار و آجیل، پیاده‌سازی‌شده با **Vue 3 + Vue Router + Vite** — کاملاً راست‌چین (RTL)، فارسی، تک‌صفحه‌ای (SPA) با مسیرهای واقعی و بهینه برای **سئو**. طراحی دقیقاً مطابق قالب اصلی (همان پالت سبز `#48b500` و طلایی `#cca000`، همان فونت وزیرمتن و همان تمام بخش‌هاست).

## ▶️ اجرا و توسعه

```bash
cd app
npm install
npm run dev      # حالت توسعه: http://localhost:5173/food-shop/
npm run build    # خروجی نهایی در app/dist
npm run preview  # پیش‌نمایش خروجی ساخت
```

نسخهٔ تک‌فایل قدیمی (HTML خالص) همچنان در `download/فروشگاه-خانم-گل.html` نگه داشته شده است.

## 🚀 انتشار روی GitHub Pages

خروجی `app/dist` در ریشهٔ ریپو کپی می‌شود (فایل `index.html` ریشه همان اپ Vue است). مسیر پایه `/food-shop/` است و برای مسیرهای عمیق SPA از فایل `404.html` (ترفند استاندارد GitHub Pages) استفاده می‌شود.

```bash
cd app && npm run build
rm -rf assets && cp -r dist/. ../    # از پوشهٔ app اجرا نشود؛ دستور کامل در ادامه
```

به‌صورت خلاصه: بعد از هر بیلد، محتویات `app/dist` را در ریشهٔ ریپو کپی و کامیت کنید.

## 🗂 ساختار پروژه

```
app/
├── index.html                ← قالب ورودی (متا، فونت، JSON-LD، ترفند 404)
├── public/                   ← robots.txt ، sitemap.xml ، 404.html ، .nojekyll
└── src/
    ├── assets/main.css       ← کل سیستم طراحی قالب اصلی (بدون تغییر)
    ├── data/                 ← catalog.js (محصولات/دسته‌ها/کدها) ، site.js (ابزارها)
    ├── services/             ← لایه اتصال به بک‌اند (فعلاً Mock/LocalStorage)
    ├── stores/               ← cart ، fav ، auth ، orders ، ui (واکنش‌گرا)
    ├── composables/useSeo.js ← عنوان/توضیح/کنونیکال/OG/JSON-LD هر صفحه
    ├── router/               ← مسیرها + گارد پنل کاربری
    ├── components/           ← هدر، مگامنو، دراور، کشوی سبد، کارت محصول، تایم‌لاین…
    └── views/                ← Home ، Products ، Product ، Cart ، Checkout ،
                                 Track ، Auth ، Account (پنل مشتری) ، Admin (پنل مدیر)
```

## 🛒 امکانات فروشگاهی

- 🖋 راست‌چین کامل و فونت **یکدست وزیرمتن** در تمام بخش‌ها
- 🧭 مگامنوی ۱۳ دسته‌بندی در دسکتاپ + دراور آکاردئونی در موبایل
- 🖼 بنر اصلی با شعار «طعم اصالت، کیفیت در هر دانه»
- 🎁 **کارت دورانی (فلیپ) بسته تخفیف** با شمارش معکوس چرخه‌ای ۲۴/۴۸ ساعته
- ⏱ **پیشنهاد شگفت‌انگیز** با شمارش معکوس تا نیمه‌شب
- 🛒 ۲۸ محصول + ۷ کالای «خرید اطمینان»؛ انتخاب وزن و **قیمت‌گذاری خودکار بر اساس وزن**
- 🔍 جستجوی زنده با پیشنهاد، فیلتر دسته/بازه قیمت/مرتب‌سازی در صفحه فروشگاه (`/products`)
- 📄 **صفحه محصول** با مسیر اختصاصی `/product/:id`، محصولات مشابه و اسکیمای Product
- 🧺 سبد خرید: کشوی کنار صفحه + صفحه کامل `/cart` + نوار شناور موبایل
- 💳 **تسویه حساب سه‌مرحله‌ای** `/checkout`: اطلاعات ارسال → فاکتور → ثبت نهایی با کد سفارش
- 🚚 سه روش ارسال (پیک/پست/تیپاکس) + ارسال رایگان بالای ۱٬۵۰۰٬۰۰۰ تومان + کدهای تخفیف
- 📦 **پیگیری سفارش** `/track` با تایم‌لاین ۴ مرحله‌ای (کد نمونه: `AS-1024`)
- 👤 **پنل مشتری** `/account`: سفارش‌ها، علاقه‌مندی‌ها، کدهای من، حساب و سطح عضویت (برنزی/نقره‌ای/طلایی)
- 🛡 **پنل مدیر** `/admin`: آمار فروش، مدیریت کامل محصولات (افزودن/ویرایش/حذف) و تغییر وضعیت سفارش‌ها
  - ورود پیش‌فرض دمو: نام کاربری `admin` و رمز `admin1234`
- 🎟 **کارت شانس روزانه** با جایزه‌های وزن‌دار و ذخیره کد در پنل
- 🤝 بخش **خرید اطمینان** با کالای روز، انتخاب روز هفته و شمارش معکوس
- 🎨 **تغییر تم زنده**: ۷ پالت آماده + ذخیره انتخاب کاربر
- ❤️ علاقه‌مندی‌ها، سبد و سفارش‌ها با ذخیره در **LocalStorage**

## 🔍 سئو

- عنوان و توضیح متای اختصاصی + **Canonical** + Open Graph برای هر مسیر
- **JSON-LD**: فروشگاه (Store) و وب‌سایت در سراسری، اسکیمای `Product` در صفحه محصول
- URL‌های تمیز و قابل اشتراک (History Mode) با فال‌بک `404.html` روی GitHub Pages
- `sitemap.xml` شامل همهٔ مسیرها و محصولات + `robots.txt`
- HTML معنایی: یک `h1` در هر صفحه، breadcrumb، لینک‌سازی داخلی مگامنو، `alt` تصاویر، `loading="lazy"`

## 🔌 اتصال بک‌اند (آینده)

تمام داده‌ها فعلاً از `LocalStorage` خوانده/نوشته می‌شوند. برای اتصال به بک‌اند واقعی کافی است بدنهٔ توابع در `app/src/stores/*` و `app/src/data/catalog.js` را با `fetch` به API خودتان جایگزین کنید؛ کامپوننت‌ها و صفحات بدون تغییر می‌مانند. ساختار سفارش و محصول در همان فایل‌ها مستند شده است.

## 🧾 نکات دمو

داده‌ها نمونه هستند؛ سبد، سفارش‌ها، حساب‌ها و کدهای تخفیف در `LocalStorage` مرورگر ذخیره می‌شوند. برای شروع تازه، حافظه مرورگر را پاک کنید.
