# 🌰 خانم گل | قالب فروشگاه اینترنتی خشکبار و آجیل

قالب کامل و **تک‌فایل HTML** برای فروشگاه اینترنتی خشکبار، آجیل و محصولات طبیعی — کاملاً راست‌چین (RTL)، فارسی، فول‌ریسپانسیو و بدون هیچ وابستگی (بدون فریم‌ورک و بدون نیاز به بیلد). تمام CSS و JS داخل همان یک فایل است.

## ▶️ اجرا

کافی است فایل را در مرورگر باز کنید:

```
download/فروشگاه-خانم-گل.html
```

یا روی سرور محلی:

```bash
python3 -m http.server 8000
# سپس: http://localhost:8000/download/فروشگاه-خانم-گل.html
```

> فایل `index.html` در ریشه، کپی همین قالب برای انتشار فوری روی **GitHub Pages** است.

## ✨ امکانات

- 🖋 راست‌چین کامل و فونت **یکدست وزیرمتن** در تمام بخش‌ها (نوار ارتباط با مشتری، هدر، بدنه و…)
- 🧭 مگامنوی ۱۳ دسته‌بندی در دسکتاپ + دراور آکاردئونی در موبایل
- 🖼 بنر اصلی تک‌اسلاید با شعار «طعم اصالت، کیفیت در هر دانه»
- 🎁 **کارت دورانی (فلیپ) بسته تخفیف** با شمارش معکوس ۴۸ ساعته
- ⏱ بخش پیشنهاد شگفت‌انگیز با شمارش معکوس ۲۴ ساعته (سقف ۲۴ تا ۴۸ ساعت)
- 🛒 ۳۳ محصول با تصویر واقعی، انتخاب وزن (۲۵۰ گرم تا ۲ کیلوگرم) و **قیمت‌گذاری خودکار بر اساس وزن** + قیمت تومان با جداکننده سه‌رقمی
- 📱 در موبایل همه شلف‌های محصول **اسکرول افقی (اسنپ)** دارند؛ بدون سرریز افقی در هیچ عرضی
- ❤️ علاقه‌مندی‌ها، سبد خرید و Mini-Cart با ذخیره در **LocalStorage**
- 🔍 جستجوی زنده، فیلتر دسته‌بندی، بازه قیمت و مرتب‌سازی صعودی/نزولی
- 🎟 **کارت شانس روزانه** (کد تخفیف، ارسال رایگان، تخفیف خرید بعدی و…)
- 🧑‍💼 بخش **مشاوره خرید** با فرم درخواست تماس
- 📦 بخش **پیگیری خرید** با تایم‌لاین وضعیت سفارش (کد نمونه: `AS-1024`)
- 🤝 بخش **خرید اطمینان**: نوار تیره لوکس با پیشنهاد روزانه یک کالای غیرخوراکی، شمارش معکوس تا پایان روز، انتخاب روز هفته و ستون اعتماد
- 🚚 **ارسال رایگان برای سفارش‌های بالای ۱٬۵۰۰٬۰۰۰ تومان** + توضیح هزینه پیک و مرجوعی
- 📩 شبیه‌سازی **ارسال پیامک** پس از ثبت سفارش موفق
- 🏷 کد تخفیف **اولین خرید**: `WELCOME10` (۱۰٪ اولین خرید)
- ☀️ نشان‌های دایره‌ای **«خورشید ضربان‌دار»** (قرمز با هاله طلایی و انیمیشن ضربان)
- 🎨 **تغییر تم زنده**: ۷ پالت آماده (سبز، اناری، زیتونی، قهوه‌ای، توسی، بنفش، آبی) از پنل بالای هدر + ذخیره انتخاب کاربر

## 🎨 پالت رنگی

تمام رنگ‌ها با CSS Variables در `:root` تعریف شده‌اند (قهوه‌ای تیره، کرم، طلایی مات، زیتونی، آجری) — برای اعمال طیف رنگی دلخواه فقط همان چند متغیر را عوض کنید.

## 🧾 نکات دمو

داده‌ها نمونه هستند و سبد خرید، سفارش‌ها و کدهای تخفیف در `LocalStorage` مرورگر ذخیه می‌شوند؛ برای شروع تازه، حافظه مرورگر را پاک کنید.
